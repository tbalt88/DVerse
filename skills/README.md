# Skills

Empty until wave 6. This holds the evolved d365-architect skill, ported from the
archived seed repo tbalt88/DVerseClaudeSkills.

Laid out to Microsoft's plugins/<name>/ marketplace convention on purpose. That
keeps the deferred option open: contributing upstream to
microsoft/power-platform-skills later, from a position of demonstrated work
rather than to establish it.

The skill is built AFTER the gates, deliberately. The gates prove which rules are
mechanically checkable; the skill then states rules that have already been shown
enforceable, rather than asserting rules that turn out not to be.
